📐 Floorplan Agent 设计建议

基于上方各步骤的 AI 辅助评分，针对"人在回环、辅助驾驶"的定位给出 Agent 的能力分层建议。

🤖 AI 主导（人工 review 即可）

设计导入、初始化、Pin/Bump 列表生成、Blockage/Halo 脚本化、报告解析、签出归档。这类步骤可由 Agent 自动生成 TCL 并执行，人工只看结果。

🧑‍💻 人机协作（Agent 提建议，人决策）

Floorplan 规格定义、Power Plan 模板生成、Pin Assignment、Floorplan QC 诊断。Agent 给出候选方案 + 推理依据，人工选择/微调。

🎨 人工主导（Agent 提供环境与数据）

Macro Placement、IO/Pad 物理规划、迭代收敛策略。需要架构 sense、dataflow 直觉。Agent 负责：dataflow 可视化、约束查询、违例热力图、修改后回归。

🛠 Agent 必备能力栈

① 调用 Innovus（TCL 生成+执行+回读日志）
② 解析 report/DEF/log（congestion、IR、timing）
③ Spec/约束的结构化存储（YAML）
④ 决策审计日志（人选了什么、为什么）
⑤ 回滚 checkpoint
