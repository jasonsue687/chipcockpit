读法：每个步骤卡片下半部「执行 skill」按实际调用顺序从上到下列出。紫=决策 playbook skill，蓝=render-tcl/run-eda-script，绿=parse-eda-report，青=version-check，黄=人工(无 skill)。NEW=本次新增的人工门。
共享 skill 复用：所有自动执行/决策步的末段都复用同两个共享 skill —— render-tcl（template + decisions.yaml → 具体 step.tcl）和 run-eda-script（--mock 跑出可解析的 SIMULATED 报告）。8 个 gate 全部复用 parse-eda-report。决策 skill 是双轨的：主 agent 读 SKILL.md playbook 对本芯片 spec/上游 eval 推理，scripts/gen_decisions.py 是无人值守兜底。9 个人工门不加载任何 skill —— 它们故意不声明 output，所以永远停在 await_human，只能由 resolve-human 清除（这正是"可换会话续跑"的持久暂停点）。
